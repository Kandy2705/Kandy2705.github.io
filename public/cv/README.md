# CV files

The portfolio can use three CV URLs:

- English Game Developer CV
- Vietnamese Game Developer CV
- Vietnamese Web Developer CV

For a fully static setup, place the files here with these names:

- `game-developer-en.pdf`
- `game-developer-vi.pdf`
- `web-developer-vi.pdf`

For the recommended Supabase setup, you can instead upload the PDFs from **Admin -> Profile** and the saved public Storage URLs will be used immediately.
